## Manual Reproduction

1. From the repository root, start a clean backend with `bash backend/scripts/reap_stale_backends.sh`, then boot the backend used by the app.
2. Run the production app with `cd mac-app && swift run ChatApp`.
3. Register or sign in as two users, and make sure both users have published message keys by opening the app after authentication.
4. DM flow: start a direct message with the second user, click the paperclip button, choose a file of 10 MB or less, send it, receive it on the other user, click `Download`, save it, and open the saved file. The saved file should match the original bytes and display the original contents.
5. Group flow: create or open a group containing both users, click the paperclip button, choose a file of 10 MB or less, send it, receive it in the group view with the sender username still shown under the bubble, click `Download`, save it, and open the saved file. The saved file should match the original bytes and display the original contents.
